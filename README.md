# 🐝 BeeSpotifyWrapped

**Live: [beespotifywrapped.onrender.com](https://beespotifywrapped.onrender.com)**

A Spotify Wrapped clone with a few things the real one doesn't have: pick your own timeframe
(last 4 weeks / last 6 months / all time), stay logged in without having to sign in every visit,
and share your stats as a link or an image.

Log in with your own Spotify account to see your own top genres, artists, and songs, or open a
shared link to view someone else's without needing an account at all.

## What it's built with

- **Backend:** Flask, server-side sessions, SQLite
- **Frontend:** React, React Router, Framer Motion
- **Deployed on:** Render, as a single service serving both the API and the built frontend
